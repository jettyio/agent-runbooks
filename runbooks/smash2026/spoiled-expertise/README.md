# Damned if You Do(n't): How Epistemic Technology Spoils Expertise

Ayman Ajaj, Mayur Joshi, Mathieu Bouchard · SMASH 2026 (Spotlight) · [Paper](https://prefigurationlab.com/docs/SMASH_2026_Spolied_Expertise_CameraReady.pdf)

> We advance a concept of spoiled expertise which takes distinct forms based on two dimensions: knowledge workers' stance of adoption of epistemic technology, and locus of evaluation of expertise. Together these two dimensions culminate into four forms of spoiled expertise: (1) slopped expertise, (2) lagging expertise, (3) shunned expertise, and (4) outdated expertise.

This runbook reruns part of the paper's analysis on Jetty in a few minutes. Change the inputs in `RUNBOOK.md`'s Parameters table to try your own.

## Default run

The default radiologist case reads as shunned expertise. Two judges coded 36 comments with κ = 0.93.

- An interpretive aid, not a measurement.
- The comment corpus is synthetic and both judges are Claude models.
