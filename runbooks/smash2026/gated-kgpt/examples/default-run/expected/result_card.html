From the abstract

We introduce gated Knowledge-Guided Prototype Transfer (KGPT), a pre-repulsion module that transfers supported-class visual residuals to missing classes using VLM similarity and an ontology-based clinical distance. A validation-free evidence gate scales transfer based on semantic relevance and residual agreement, thereby limiting unsupported extrapolation.

Try next

  • Zero gap shrink — borrowed correction is always exactly right — With gap_shrink=0 every class has the same modality gap, so the borrowed visual correction needs no scaling. Does the gate, by reducing the effective step, actually hurt missing-class recall compared to ungated transfer? This is the cleanest test of whether the gate adds value beyond overshoot-prevention.
    {"gap_shrink": 0}
  • Middle grade with zero support — does a central missing class reveal a gate-closed configuration? — Setting support_counts to 3,1,0,1,0 leaves Moderate unsupported and flanked by two supported neighbours (Mild and Severe). Because the two neighbours may be nearly equidistant in VLM space, the NN margin above the candidate-row median (q_vlm) can be near zero, triggering a gate-closed class and showing how the gate refuses to act when evidence is ambiguous.
    {"support_counts": "3,1,0,1,0"}
  • Lower fixed beta 0.5 — is a smaller step as safe as the gate at beta=1? — The beta sweep shows ungated NTR is around 18–24% at β=0.45–0.6. Comparing ungated β=0.5 to gated β=1 tests whether evidence-adaptive scaling adds value beyond simply turning down the step size. If gated β=1 still beats ungated β=0.5 on ΔMCR with lower NTR, the gate earns its keep.
